# AutoTrickOrTreat

This script automatically interacts with doors that have 'Trick or Treat' above the interaction button in the Storage Hunter open-world game. It is designed to streamline the process of collecting items during Halloween events by automatically triggering interactions with qualifying doors.

## Installation

1. Open Roblox Studio.
2. Create a new script or open an existing one.
3. Copy and paste the contents of `scripts/auto_interact_doors.lua` into the script.
4. Place the script in the `StarterPlayerScripts` folder in the Roblox Studio hierarchy to ensure it runs when the player joins the game.

## Usage

The script will automatically interact with doors that meet the specified criteria. No additional setup is required.
